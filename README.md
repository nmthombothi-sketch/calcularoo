# Calcularoo 🦘

**The World's Decision Calculator** — free financial, health, travel and investment tools that give you a verdict, not just a number.

## Live Site
[calcularoo.com](https://www.calcularoo.com)

## What's Inside
- 92 pages total
- 35 decision calculators (Money, Career, Family, Travel, Business, Housing, Health, Investing)
- 50+ utility calculators (loan, mortgage, BMI, calorie, tip, etc.)
- Pure static HTML/CSS/JS — no build step, no dependencies
- Deploys to any static host (Cloudflare Pages, Netlify, Vercel, GitHub Pages)

## Deploy
Just drag the folder into Cloudflare Pages or run:
```
netlify deploy --dir . --prod
```

## Stack
- HTML / CSS / Vanilla JS
- Fonts: Bebas Neue + DM Sans (Google Fonts)
- Ads: Google AdSense (`ca-pub-6108324382808705`)
- No frameworks, no build tools, no npm
